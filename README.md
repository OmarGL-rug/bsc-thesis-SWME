# PhD-RUG
This repository contains the code I've written during my PhD at the University of Groningen. 

How to run a simulation:
1. Navigate to "Spatially Adaptive Moment Models/Nonlinear-systems/Config-files". In "config.txt" specify your desired initial conditions, boundary conditions, and method used to solve the differental equations.
2. Run "Spatially Adaptive Moment Models/Nonlinear-systems/main.py".

The config files used in Micro-Macro Simulation of Shallow Water Moment Equations are saved in "Spatially Adaptive Moment Models/Nonlinear-systems/Config-files/Config Micro-Macro".
